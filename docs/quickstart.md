
# Linux Server Check 快速上手

一句话概括：**基于 Go 语言 + Cobra + gopsutil 技术开发的 Linux 服务器健康诊断工具，支持负载/CPU/内存/磁盘/线程/网络/内核参数的实时监控与异常检测，自动生成 HTML 报告，解决运维人员快速定位系统问题的需求。**

## 工具定位

基于 Go 语言开发的 Linux 服务器健康诊断工具，采用模块化架构设计（Checker/Reporter/Cmd 三层分离），集成 Cobra CLI 框架和 gopsutil 系统信息库。实现了负载、CPU、内存、磁盘、线程、网络、内核参数等 8 大类检查能力，支持实时监控（类似 top）、CLI 交互式检查和 HTML 报告生成。通过预设规则自动检测异常并告警，帮助运维人员快速定位系统问题。

**技术亮点**：
- Go 语言并发编程，资源占用低，启动速度快
- 模块化设计，易于扩展新的检查模块
- 实时监控模式，支持优雅退出（Ctrl+C）
- HTML 报告生成，支持模板化定制
- 多维度异常检测，阈值可配置

## 解决的问题

### 系统性能问题

| 问题场景 | 检测指标 | 异常阈值 |
|----------|----------|----------|
| CPU过载 | 系统负载、CPU使用率 | 负载 >= 1.2×核心数，使用率 >= 85% |
| 软中断风暴 | CPU软中断使用率 | >= 10% |
| IO瓶颈 | CPU IO等待时间 | >= 10% |

### 内存问题

| 问题场景 | 检测指标 | 异常阈值 |
|----------|----------|----------|
| 内存耗尽 | 可用内存占比 | < 15% |
| 内存泄漏 | 黑洞内存（无法归类的消耗） | 持续增长 |
| 内核内存异常 | Slab、Vmalloc等 | 异常增长 |

### 存储问题

| 问题场景 | 检测指标 | 异常阈值 |
|----------|----------|----------|
| 磁盘空间不足 | 分区使用率 | > 85% |
| Inode耗尽 | Inode使用率 | > 85% |
| 磁盘IO繁忙 | IO利用率 | > 90% |

### 线程与进程问题

| 问题场景 | 检测指标 | 异常阈值 |
|----------|----------|----------|
| 线程数接近上限 | 当前线程数/threads-max | > 80% |
| 僵尸进程 | 僵尸进程数量 | > 0 |
| 线程泄漏 | 进程线程数排行 | 某个进程线程数异常高 |

### 网络问题

| 问题场景 | 检测指标 | 异常阈值 |
|----------|----------|----------|
| 网络流量异常 | 网卡接收/发送速率 | > 25MB/s |

### 配置问题

| 问题场景 | 检测指标 | 异常阈值 |
|----------|----------|----------|
| 内核参数不合理 | 参数匹配率 | < 60% |

### 典型使用场景

1. **服务器告警排查**：收到监控告警后，快速运行检查定位是CPU、内存还是磁盘问题
2. **性能问题诊断**：运行实时监控观察各指标变化，找到性能瓶颈
3. **定期健康巡检**：生成HTML报告，存档备查
4. **内核参数审计**：检查服务器内核参数是否符合最佳实践

## 快速使用

### 检查命令

```bash
# 查看可用检查命令
./server_check check

# 负载/CPU检查（每秒一次，默认20次）
./server_check check load
./server_check check load -c 10    # 指定检查次数

# 内存检查（每秒一次，默认20次）
./server_check check mem
./server_check check mem -c 10     # 指定检查次数

# 磁盘检查（一次性输出）
./server_check check disk

# 线程检查（一次性输出）
./server_check check threads

# 实时多区域监控（类似top命令）
./server_check check top
./server_check check top -d 60     # 运行60秒后自动退出
```

### 报告命令

```bash
# 生成 HTML 报告（每项检查5次）
./server_report report
./server_report report -c 3        # 指定检查次数
```

## 检查内容

### 1. 负载与 CPU

| 检测项 | 说明 |
|--------|------|
| CPU核心数 | 获取物理CPU核心数量 |
| 系统负载 | 1/5/15分钟平均负载 |
| CPU使用率 | 用户态、系统态、空闲、Nice、IOWait、硬中断、软中断、Steal |
| 任务状态 | 总任务数、运行中、阻塞、僵尸进程、单进程数、线程数 |

### 2. 内存

| 检测项 | 说明 |
|--------|------|
| 内存总量/空闲/可用 | 基础内存信息 |
| 缓冲区/缓存 | Buffers、Cached、Active、Inactive |
| 内核内存 | Slab、SReclaimable、SUnreclaim、KernelStack、PageTables |
| 进程内存 | 应用程序实际使用内存 |
| Vmalloc | 虚拟内存使用 |
| HugePages | 大页内存配置 |
| 黑洞内存 | 无法归类的内存消耗 |

### 3. 磁盘

| 检测项 | 说明 |
|--------|------|
| 分区信息 | 设备名、挂载点、文件系统类型 |
| 空间使用 | 总大小、已用、可用、使用率 |
| Inode使用 | Inode总数及使用率 |

### 4. 线程

| 检测项 | 说明 |
|--------|------|
| 内核参数 | pid_max、threads-max、ulimit -u、max_map_count |
| 当前线程数 | 系统当前线程总数 |
| 线程使用率 | 当前线程数占最大限制的比例 |
| 进程排名 | 线程数最多的前10个进程 |

### 5. 磁盘 IO（仅报告）

| 检测项 | 说明 |
|--------|------|
| IOPS | 每秒读写次数 |
| 吞吐量 | 每秒读写KB数 |
| 队列长度 | 平均IO队列深度 |
| 等待时间 | 平均等待时间、读等待、写等待 |
| 服务时间 | 平均服务时间 |
| IO利用率 | 设备繁忙程度 |

### 6. 网络（仅报告）

| 检测项 | 说明 |
|--------|------|
| 网卡信息 | 名称、MAC地址、IP地址、状态 |
| 流量统计 | 接收/发送包数、KB数 |
| 压缩包 | 接收/发送压缩包数 |
| 多播包 | 接收多播包数 |
| 平均包大小 | 接收/发送数据包平均大小 |

### 7. 内核参数（仅报告）

| 检测项 | 说明 |
|--------|------|
| 参数对比 | 系统当前值与模板推荐值对比 |
| 匹配率统计 | 匹配/不匹配参数数量及百分比 |

### 8. 主机信息（仅报告）

| 检测项 | 说明 |
|--------|------|
| 主机名 | 系统主机名 |
| 内核版本 | Linux内核版本号 |
| 操作系统 | 发行版及版本 |
| 运行时间 | 系统开机运行时长 |
| CPU信息 | 型号、核心数 |
| 内存总量 | 物理内存大小 |
| 数据盘 | /data目录挂载磁盘大小 |
| IP地址 | 本机IP |

## 报告说明

运行 `report` 命令后，报告保存在 `reports/` 目录，文件名为 `server_report_<IP>_<时间戳>.html`。

报告包含：概览、主机信息、负载信息、内存信息、磁盘信息、磁盘IO信息、网络信息、内核配置。

## 异常检测规则

| 检查项 | 异常条件 |
|--------|----------|
| 系统负载 | 1分钟负载 >= 1.2 × CPU核心数 |
| CPU软中断 | 软中断使用率 >= 10% |
| CPU IO等待 | IOWait >= 10% |
| CPU使用率 | 总使用率 >= 85% |
| 内存使用率 | 可用内存占比 < 15% |
| 磁盘使用率 | 空间使用率 > 85% |
| Inode使用率 | Inode使用率 > 85% |
| 线程使用率 | 当前线程数/threads-max > 80% |
| 磁盘IO | IO利用率 > 90% |
| 网络流量 | 接收/发送 > 25MB/s |
| 内核参数 | 匹配率 < 60% |
